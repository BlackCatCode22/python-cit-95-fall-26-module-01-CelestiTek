Python Source Code Naming Standard

Beginning with Module 01, use standard Python-style names for your source-code files:

Use lowercase letters.

Separate words with underscores.

Do not use spaces.

Do not use hyphens.

End Python source-code filenames with .py.

Use descriptive names that tell us what the program does.

For example:

worked_exercise_2_2.py

worked_exercise_2_3.py

chapter_01_practice.py

chapter_02_practice.py

chapter_03_practice.py

Use the same general convention for your Python variable names. For example:

hours_worked

hourly_rate

gross_pay

Good programmers make their code easy for other programmers to read.
